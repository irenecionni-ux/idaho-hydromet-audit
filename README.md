# Idaho Hydro-Meteorological Network Audit

This repository contains structural and operational analyses of the Idaho hydro-meteorological observation network, integrating:

- SNOTEL
- Synoptic
- ITD RWIS

## Objectives

- Assess network redundancy
- Identify spatial and temporal gaps
- Evaluate data continuity
- Support statewide hydrometeorological integration

## Structure

- `project/notebooks/` → analytical notebooks
- `project/scripts/` → reusable code
- `project/data/` → raw and processed datasets
- `project/outputs/` → figures and tables

## Phase 1
Structural network audit and spatial overlap analysis.

## Phase 2
SNOTEL metadata and data reliability analysis.
